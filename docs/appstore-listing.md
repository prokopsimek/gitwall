Description:

```
Gitwall keeps the pull requests and issues you care about one glance away. It gathers open pull requests (merge requests) and issues from the GitHub and GitLab repositories you choose, sorts them by latest activity and shows review, CI, draft and merge-conflict state at a glance. Click an item to open it in your browser.

WORKS WITH YOUR HOSTS
• GitHub.com and GitHub Enterprise Server
• GitLab.com and self-managed GitLab (16 or newer)
• Several accounts at once, in one list

PRESETS
Every account starts with presets for pull requests and issues assigned to you and reviews waiting for you. Save more named views on top. Combine repositories, organizations or groups from any account, choose pull requests, issues or both, and filter by author, review request, assignee, labels, review state, CI state, drafts, age, milestone or text.

WIDGETS
Add desktop widgets in four sizes: Counter, List, Board and Wide Board. Every widget shows the preset you pick for it, and you can add as many as you like.

MENU BAR
The menu bar popover lists the selected preset and can show the number of items waiting for you next to the icon. Refresh on demand or every 1 to 30 minutes.

NOTIFICATIONS
Get a local notification when something changes in a preset: new items, review requests, approvals, requested changes, failed CI, merges and closes. Switch each event on or off per preset.

PRIVATE BY DESIGN
Gitwall has no server and no analytics. Your access tokens live in the macOS Keychain and every request goes directly from your Mac to GitHub or GitLab. The source code is open under the MIT license.

Sign in with GitHub or GitLab, or use a personal access token with read access.
```

```
NO ACCOUNT NEEDED — SAMPLE DATA MODE

Gitwall shows pull requests and issues from the reviewer's own GitHub or GitLab account, but every feature can be reviewed without one. "Look around with sample data" fills the whole app with fictional pull requests and issues. Nothing is saved, no token is stored and no network access is needed.

Where to start sample data (any of these, whenever no account is connected):
- the walkthrough on first launch, step "Connect an account";
- Gitwall Settings > Accounts > "Look Around with Sample Data". Open Settings with Cmd+, or from the menu bar icon. This matters if this Mac already ran an earlier Gitwall build: the walkthrough is only shown once;
- the menu bar icon: the popover offers it under "Add Account...";
- the Add Account sheet, bottom left;
- menu Help > Look Around with Sample Data.

What to try with sample data:
1. Menu bar icon: the popover lists the selected preset; switch presets at the top. The number next to the icon is the count of "Waiting for my review".
2. Menu Window > Gitwall (Cmd+1): every preset in the sidebar, search at the top.
3. Settings > Presets: change a preset's filters, or type a query such as: is:pr AND (label:bug OR label:security). Notifications are off by default and are switched on per preset.
4. Menu View > Refresh Now (Cmd+R), or the arrow in the popover: a new review request arrives. With notifications allowed and switched on for that preset, a notification appears.
5. Settings > Repositories lists the sample repositories and organizations; Settings > General has the refresh interval, the Dock icon and Launch at login.
6. Desktop widgets: right-click the desktop > Edit Widgets... > search "Gitwall" > add a widget. Without an account the widgets show the sample data; right-click a widget > Edit "Gitwall" > choose a preset, so each widget can show a different view.
7. Clicking a sample item explains that it is sample data, because fictional items have no page on GitHub or GitLab.
8. Settings > Accounts > "Stop" ends sample mode.

A screen recording that goes through all of this, starting from a fresh installation, is attached to this submission (App Review Information > Attachment).

Signing in with a real account: we cannot provide shared credentials, because GitHub e-mails a verification code to the account owner when someone signs in from a new device, which would block the reviewer. Any free GitHub account works: Add Account... > "Sign in with GitHub" (enter the code shown at github.com/login/device), or "Use a personal access token instead" with a fine-grained read-only token (Pull requests, Issues, Commit statuses, Contents). There is no Gitwall account and no Gitwall server; data goes straight from GitHub or GitLab to the Mac, and tokens stay in the macOS Keychain.

The app shows a Dock icon by default; Settings > General can switch it to a pure menu bar app.
```
