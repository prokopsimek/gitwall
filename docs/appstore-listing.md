## Version information (0.1.0)

Description:

```
Gitwall keeps the pull requests and issues you care about one glance away. It gathers open pull requests (merge requests) and issues from the GitHub and GitLab repositories you choose, sorts them by latest activity and shows review, CI, draft and merge-conflict state at a glance. Click an item to open it in your browser.

WORKS WITH YOUR HOSTS
• GitHub.com and GitHub Enterprise Server
• GitLab.com and self-managed GitLab (16 or newer)
• Several accounts at once, in one list

PRESETS
Save named views such as “My pull requests”, “Waiting for my review” or “All open”. Combine repositories, organizations or groups from any account, choose pull requests, issues or both, and filter by author, review request, assignee, labels, review state, CI state, drafts, age, milestone or text.

WIDGETS
Add desktop widgets in four sizes: Counter, List, Board and Wide Board. Every widget shows the preset you pick for it, and you can add as many as you like.

MENU BAR
The menu bar popover lists the selected preset and can show the number of items waiting for you next to the icon. Refresh on demand or every 1 to 30 minutes.

NOTIFICATIONS
Get a local notification when something changes in a preset: new items, review requests, approvals, requested changes, failed CI, merges and closes. Switch each event on or off per preset.

PRIVATE BY DESIGN
Gitwall has no server and no analytics. Your access tokens live in the macOS Keychain and every request goes directly from your Mac to GitHub or GitLab. The source code is open under the MIT license.

Sign in with GitHub or GitLab, or use a personal access token with read access.
```

- Notes:

```
Gitwall reads pull requests and issues through the GitHub and GitLab APIs with a personal access token that the user creates on their own account; there is no Gitwall account or server.

To test: the app opens a short walkthrough on first launch. On "Connect an account" choose "Sign in with GitHub", which shows a code to enter at github.com/login/device with your own GitHub account, or click "Use a personal access token instead" and paste any GitHub token with read access to a public repository (a fine-grained token with read-only “Pull requests”, “Issues” and “Metadata” permissions is enough). Then tick a repository on the next step. The main window, the menu bar popover and the presets fill within a few seconds.

Desktop widgets: right-click the desktop › Edit Widgets… › search “Gitwall” › drag a widget to the desktop › right-click it › Edit “Gitwall” › choose a preset.

The app shows a Dock icon by default; it can be switched off in Settings › General to run as a pure menu bar app.
```
